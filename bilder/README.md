# Bilder-Ordner

Lade hier deine Fotos mit genau diesen Dateinamen hoch — sie werden dann automatisch
auf der Website angezeigt (kein Code-Änderung nötig). Bis dahin zeigt die Seite an
diesen Stellen einen eleganten Platzhalter.

| Datei | Verwendung |
|---|---|
| `logo.png` | Logo in der Navigation & Favicon |
| `dimitri.jpg` | Portraitfoto im "Über mich"-Bereich |
| `business_thumb.jpeg` | Vorschaubild Portfolio-Kategorie "Business" |
| `business1.jpg` – `business4.jpg` | Weitere Bilder in der Business-Galerie (Lightbox) |
| `portrait_thumb1.jpg` | Vorschaubild Portfolio-Kategorie "Portrait" |
| `portrait1.jpg` – `portrait7.jpg` | Weitere Bilder in der Portrait-Galerie (Lightbox) |
| `hochzeit_thumb.jpeg` | Vorschaubild Portfolio-Kategorie "Hochzeit" |
| `hochzeit1.jpeg` – `hochzeit4.jpeg` | Weitere Bilder in der Hochzeit-Galerie (Lightbox) |

Videos (Vorschaubild fürs Portfolio) gehören in den `videos/`-Ordner, siehe dort.

**Tipp:** Für beste Performance Bilder vorher komprimieren (z. B. mit Squoosh oder
TinyPNG) und als `.jpg`/`.webp` in max. ca. 1600px Breite hochladen.
